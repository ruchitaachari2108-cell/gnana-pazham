# Assets & Licences

Everything you see and hear in **Gnana Pazham — The Race of Wisdom** was created for this
project in code. No third-party models, textures, images, music or sound files are used.

| Asset | Source | Licence |
| --- | --- | --- |
| Ganesha, Mooshika, Murugan, Peacock, Shiva, Parvati, Nandi, Gnana Pazham | Procedural low-poly geometry written for this project (`src/player/Ganesha.js`, `src/rival/Murugan.js`, `src/characters/Divine.js`) | Original work of the team |
| Worlds (Surya, Chandra, Mangala, Kailasa), temples, trees, mountains, clouds, lava, meteors | Procedural geometry (`src/world/*`) | Original work of the team |
| Obstacles, Ladoos, Modaks | Procedural geometry (`src/obstacles/*`, `src/collectibles/*`) | Original work of the team |
| Glow / particle sprites | Generated at runtime on a `<canvas>` (`src/utils/LowPoly.js`) | Original work of the team |
| Music and all sound effects | Synthesised live with the Web Audio API (`src/audio/AudioManager.js`) | Original work of the team |
| UI icons | Unicode emoji rendered by the player's own system font | No asset shipped |
| **Three.js** (3D engine) | https://github.com/mrdoob/three.js | MIT License |
| **Vite** (build tool, dev only) | https://github.com/vitejs/vite | MIT License |
| **Cinzel** font | Google Fonts — https://fonts.google.com/specimen/Cinzel | SIL Open Font License 1.1 |
| **Nunito** font | Google Fonts — https://fonts.google.com/specimen/Nunito | SIL Open Font License 1.1 |

If the Google Fonts cannot load, the game falls back to system fonts and remains fully playable.

The story is the traditional, public-domain tale of the Gnana Pazham.
